# Картограф — Studio 03

Автономная песочница для создания локаций НРИ. Без экономики, внешних библиотек, аккаунтов и сетевых запросов. Не является копией CityRT; код, геометрия и процедурная графика созданы для этого проекта.

## Что нового в Studio 03

- **Библиотека: 97 элементов и инструментов**, а не 97 отдельных рисунков. Разделы: ландшафты, дороги и мосты, здания, природа, предметы, интерьеры, свет и анимации. Карточки используют реальные рендереры объектов.
- Поиск по всем разделам, избранное и недавние. Эти предпочтения сохраняются в текущем браузере отдельно от JSON карты. `/` фокусирует поиск.
- **28 новых предметов:** фонтан, статуя, скамья, указатель, поленница, клумба, грибы, камыш, кувшинки, причал, деревянный мост, надгробие, руины, наковальня, горн, факел, знамя, кристаллы, портал, мельница, водяное колесо, книги, стул, круглый стол, свечи, стойка оружия, мешки, поваленное дерево.
- Шесть покрытий дороги: грунт, брусчатка, тропа, гравий, каменные плиты и настил. Детализированные материалы земли, камня и дерева. Дуб, ель, ива и сухое дерево. Каменные стены, заборы и руины.
- **Россыпь предметов кистью:** радиус, шаг, случайный поворот. Весь жест отменяется одной командой; кисть обходит препятствия. Для воды и точного декора используйте одиночную постановку.
- **Сцена:** туман, дождь, снег, ветер и общая пауза. Движутся вода, кроны, фонтан, знамя, мельница, водяное колесо, портал; добавлены дым и искры. Учитывается системный `prefers-reduced-motion`. Снег — эффект осадков, не автоматическая перекраска всей карты.
- **Слои:** дороги, вода, здания/стены, деревья, предметы/мебель, подписи, тени. Скрытые объекты не выбираются; видимость учитывается в PNG, но геометрия препятствий сохраняется.
- Миникарта для перемещения камеры и **линейка I** с расстоянием в футах по текущему масштабу. Измерение не изменяет карту и не попадает в экспорт.
- Новый интерфейс: библиотека слева, вкладки «Свойства / Слои / Сцена» справа, единый набор значков. На телефоне библиотека и настройки открываются отдельными панелями.

Старые карты открываются; формат проекта обновлён до `schemaVersion: 4`. Сохранённые ранее карты не заменяются новой демо-сценой автоматически: сохраните резервную копию и выберите «Сцена → Демо-карта», чтобы увидеть новое окружение.

## Разработка и localhost

Нужен **Node.js 20+**. Внешних npm-зависимостей нет; `npm install` не требуется.

```bash
git clone https://github.com/Yokami-L9/kartograf.git
cd kartograf
npm run dev
```

Откройте **http://localhost:5173**. Сервер доступен только с этого компьютера (127.0.0.1). При изменениях в `src/` редактор пересобирается, страница автоматически обновляется. Перед изменениями скачайте резервную копию важной карты в JSON.

```bash
npm run build  # собрать автономный index.html
npm run check  # проверить синтаксис и актуальность сборки
npm test       # проверить сборку и локальный HTTP-сервер
npm start      # localhost без автоматического обновления
```

Если порт занят: `npm run dev -- --port 5174`.

**Mac:** запустите `bash launch.command` из папки проекта. Для запуска двойным щелчком сначала выполните `chmod +x launch.command`, затем откройте этот файл. Он запускает сервер и открывает браузер. Если Node.js не найден, используется Python 3 (без автоматического обновления). Нужен хотя бы один из этих интерпретаторов. macOS может запросить разрешение на запуск скачанного скрипта; отключать защиту системы не требуется. Остановить сервер: Control+C в окне терминала.

**Без localhost:** обычный `index.html` по-прежнему открывается напрямую в браузере.

## GitHub

Репозиторий проекта: https://github.com/Yokami-L9/kartograf. Код публичный; личные карты и локальное хранилище пользователей в него не отправляются.

Рекомендуемый процесс: ветка задачи → изменения в `src/` → сборка и тесты → pull request → проверка → merge в `main`. В `.github/workflows/check.yml` подготовлены автоматические проверки сборки и локального сервера. Полный браузерный набор `qa/` в этот workflow не входит.

Структура:

- `src/` — редактируемые исходники;
- `index.html` — сгенерированный автономный редактор (не редактировать вручную);
- `scripts/` — сборка, localhost, проверки;
- `qa/` — браузерные регрессии и отчёты предыдущей проверки редактора;
- `AGENTS.md` — правила разработки для AI-инструментов.

Карты сохраняются в браузере и JSON-файлах, **не в GitHub**. Хранилище для `file://` отличается от `http://localhost:5173`; для переноса карты сохраните JSON в старом редакторе и откройте его на localhost. Не меняйте порт без необходимости: другой порт — другое локальное хранилище.

Не загружайте в репозиторий токены, пароли, `.env`, приватные карты и временные экспорты. Их защита не заменяется одним `.gitignore`: всегда проверяйте состав коммита.

## Быстрый сценарий

1. D — нарисовать улицу.
2. U — выбрать архитектурный стиль и растянуть прямоугольник квартала.
3. V — выбрать отдельный дом. Изменить ширину, глубину, крышу, высоту или этажность.
4. K / кнопка «Интерьер» — снять крыши. Кнопки 1–3 переключают этажи.
5. J — внутренние стены. S — объекты и мебель.
6. M — готовые наборы: таверна, святилище, подворье и лагерь.
7. «Сохранить» — резервная копия JSON. «Открыть» — загрузить её.

## Управление

- Пробел + перетаскивание / правая кнопка — перемещать карту.
- Колесо мыши — масштаб; короткие движения трекпада — панорамирование.
- Command+Z / Control+Z — отменить; Shift+Command+Z / Control+Y — повторить.
- Command+D / Control+D — копировать объект вместе с привязанной мебелью и стенами.
- [ / ] — повернуть объект на 15 градусов.
- Delete — удалить выбранное; N — день/ночь.
- «?» — встроенная справка; на узком экране она также доступна в библиотеке и вкладке «Сцена».
- I — линейка; / — поиск; значок паузы в шапке — остановить/включить анимации.

## Как работают кварталы

При наличии дороги дома появляются вдоль неё, входами к улице. Без дороги — свободная застройка. Генератор учитывает воду, реки, дороги, крепостные стены, перепады высот, существующие постройки и часть окружения. Область ограничена 180 новыми домами на запуск.

Плотность, размер и отступ применяются кнопкой «Применить параметры». «Другой вариант» меняет seed. Дом после ручного изменения защищён от замены. Удаление дома через выбор + Delete сохраняет пустой участок в исключениях квартала. Кнопка «Застроить удалённые участки» снимает эти исключения. Разгруппировка оставляет все дома как отдельные объекты.

## Архитектура и этажи

Пять стилистических наборов: старый город, деревня, север, южный город, магический. Три типа прямоугольных крыш. 1–3 этажа. Планировки задаются отдельно для каждого этажа. Автообстановку можно отключить; ручная мебель и внутренние стены закрепляются за этажом и домом при размещении внутри его контура. Движение, поворот и изменение размеров дома обновляют привязанные объекты.

## Масштаб

По умолчанию 10 пикселей мира соответствуют клетке в 5 футов: дом шириной 44 px имеет ширину 22 фута. В настройках карты размер клетки меняется; этот же размер используется при VTT-экспорте. Старые файлы сохраняют прежний масштаб 50 px на клетку.

## Данные и экспорт

- Автосохранение в localStorage при доступности хранилища; зависит от браузера и режима просмотра.
- JSON — редактируемый проект. Импорт поддерживает прежние файлы Картографа, проверяет базовую структуру и координаты.
- PNG — 4000×2600, текущий вид (крыши/интерьеры, сетка, ночь), без интерфейса и выделения.
- Видео — шестисекундная запись, формат зависит от MediaRecorder браузера.
- Universal VTT (.dd2vtt) — изображение, контуры, двери, свет и стены текущего этажа. Видимость слоёв влияет на изображение; контуры и источники света экспортируются из геометрии проекта, независимо от скрытия слоёв. Структура проверена программно; импорт в конкретную версию Foundry/модуля не тестировался.

**Резервные копии:** скачивайте JSON, автосохранение не заменяет файл. Хранилище HTML-предпросмотра может быть временным. Сервер и облачная база не подключены.

## Честные ограничения

Это 2D/2.5D-редактор сверху, не полноценный 3D, не готовый VTT и не коммерчески завершённый продукт. Нет вращения камеры, прогулки от первого лица, учётных записей, совместной работы, тумана войны или импорта пользовательских художественных пакетов. Поле фиксировано 2000×1300. Генерация кварталов прямоугольная, участки не являются кадастровыми полигонами. Ручные свободные формы имеют упрощённые интерьеры. Процедурная графика не заменяет художественную библиотеку.

Проверка проводилась в Chromium на Linux, в том числе ширина 390 px и тёмная тема. Safari на реальном Mac и мобильные жесты отдельно не сертифицированы.

## Для разработки

`python3 build.py` собирает автономный HTML из `src/`. Исходники читаемы и не минифицированы. Браузерные тесты требуют Python Playwright и Chromium (это отдельная зависимость QA, не приложения):

```bash
python3 qa/regression.py      # прежние функции: 32 проверки
python3 qa/extended.py        # наборы, миграция, видео: 9 проверок
python3 qa/studio.py          # библиотека, слои, погода, UI: 45 проверок
python3 qa/localhost_check.py # localhost, автосохранение, live reload, PNG
```

Тесты используют `/usr/local/bin/chromium`; `qa/studio.py` также принимает переменную `CHROMIUM`. Результаты — `qa/results.json`, `qa/extended-results.json`, `qa/studio-results.json`. Они не заменяют проверку на реальном Mac. Studio-проверки включают действия мышью, сохранение настроек, пиксельную проверку паузы/анимации, светлую/тёмную тему и экран 390 px.

`src/7_studio.js` содержит каталог, SVG-значки, процедурные материалы и предметы, интерфейс библиотеки, слои, атмосферу и новые инструменты. Он подключается после `6_sandbox.js`, перед `5_boot.js`. Новую графику и связанные карточки добавляйте здесь; не правьте сгенерированный HTML.
